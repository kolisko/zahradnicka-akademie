# Bezpečnostní zásady

## Podporovaná verze

Bezpečnostní opravy se vztahují na aktuální stav větve `main`. Starší revize a odvozené kopie nejsou samostatně podporovány.

## Hlášení zranitelností

Bezpečnostní problém nezveřejňujte v issue, pull requestu ani diskusi. Použijte GitHub **Private vulnerability reporting** přes kartu **Security → Advisories → Report a vulnerability**.

Do hlášení uveďte:

- postiženou část a revizi;
- předpoklady a přesný postup reprodukce;
- možný dopad;
- bezpečný důkaz problému bez skutečných osobních údajů a přístupových údajů;
- případný návrh opravy.

Nevkládejte skutečná hesla, tokeny ani údaje třetích osob. Ověřování provádějte pouze proti systémům a datům, k nimž máte oprávnění. Po potvrzení problému bude náprava koordinována neveřejně a zveřejněna až po odstranění rizika.
